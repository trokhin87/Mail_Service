# MailService

## 1. Название и назначение сервиса
MailService — микросервис, отвечающий за отправку поздравлений пользователям. Он постоянно работает, а в определенное время суток, проверяет наличие пользователей с днем рождения сегодня и отправляет письма с поздравлениями на указанные email-адреса.

## 2. Архитектура и зависимости
### Технологии и фреймворки:
- ASP.NET Core
- Swashbuckle (Swagger) для документации API
- Serilog для логирования
- HttpClient для взаимодействия с [DBProxy(микросервис)](https://github.com/Gandoler/OTSC_DBProxy)

### Взаимодействие с другими микросервисами:
- Получает данные о пользователях из другого микросервиса  через HTTP-запросы.

### Внешние сервисы:
- SMTP-сервер для отправки писем.

## 3. Способы запуска сервиса

### Запуск через Docker:
```sh
docker-compose up --build
```

### Альтернативный запуск без Docker:
```sh
dotnet run
```

### Переменные окружения (.env):
| Переменная       | Описание |
|------------------|----------|
| SMTP_HOST       | Адрес SMTP-сервера |
| SMTP_PORT       | Порт SMTP-сервера |
| SMTP_USER       | Логин для SMTP |
| SMTP_PASSWORD   | Пароль для SMTP |

## 4. API документация
Документация API доступна в Swagger:
```
http://localhost:5000/swagger/index.html
```
### Основные эндпоинты:
- **POST /api/Mail/send_congratulations** — отправляет поздравления пользователям.
  - **200** — поздравления успешно отправлены.
  - **400** — ошибка при отправке поздравлений.
